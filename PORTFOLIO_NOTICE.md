# Portfolio Notice

Hermes Trading OS is a public systems-engineering case study derived from a private trading automation project.

This repository is intended to document:

- system architecture
- risk governance
- execution lifecycle design
- operational SOPs
- observability and journaling patterns
- testing and acceptance methodology
- sanitized examples and illustrative components

This repository intentionally excludes:

- exact trading strategy logic
- indicator thresholds
- entry and exit formulas
- private prompts or proprietary research notes
- account numbers
- broker server names
- credentials
- API keys
- SSH configuration
- VPS IP addresses
- production logs
- live trade tickets
- exact deployment paths
- private Git history

Any sample data in this repository is illustrative and sanitized. It is not a trading recommendation, not a performance claim, and not sufficient to reconstruct the private implementation.
